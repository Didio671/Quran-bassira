# Quran-bassira

Quran-bassira est une base de projet pour un site inspiré des réseaux sociaux (type Facebook), mais dédié au Quran, à la mémorisation (hifz) et à l'accompagnement par intelligence artificielle.

## Objectif

Créer une plateforme communautaire où les utilisateurs peuvent :

- publier leurs progrès et objectifs de mémorisation ;
- rejoindre des groupes de révision ;
- utiliser des outils de suivi hifz ;
- bénéficier d'un assistant IA pour planifier, réviser et apprendre.

## Prototype inclus

Le dépôt contient une première page statique (`index.html`) qui présente :

- un fil social ;
- des outils de mémorisation ;
- un panneau Assistant IA ;
- une section communauté.
